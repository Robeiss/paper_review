# V3 Iteration Roadmap

V3 focuses on making the product usable for one school before expanding to multiple schools in V4.

## Now

- Rule change item management in the admin console.
- Student personal checklist progress.

## Next

- Rule preview before publishing a version.
- Rule grouping and filtering in the admin console.
- Student print-before-submit checklist view.
- Exportable student checklist report.
- Account management for students and maintainers.
- Backend service layer and API tests.
- Persistent session or JWT-based authentication.

## Later

- Word upload and semi-automatic format checks.
- Multi-school templates and tenant isolation in V4.
