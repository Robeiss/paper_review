# 论文格式可视化样张

一个基于 Vue 的论文格式交互式模板原型。页面模拟一篇完整论文，用户悬浮或点击不同论文区域时，可以查看对应格式要求、常见错误和规则更新时间。

## 当前功能

- 模拟论文全文结构：封面、声明页、摘要、目录、正文标题、正文段落、图、表、公式、参考文献、致谢和附录。
- 学生登录后查看论文格式样张。
- 管理员登录后进入后台管理。
- 左侧目录导航：点击后跳转到对应论文模块。
- 中央论文样张：以接近纸张的样式展示虚构论文内容。
- 右侧规则面板：展示当前模块的字体、字号、行距、缩进、编号、注意事项和常见错误。
- 规则数据由 Python 后端提供，前端保留本地备用数据。
- 无真实个人信息：样张使用完全虚构的论文主题、姓名、学院和参考文献。
- 版本变更摘要：展示上一版到当前版的格式规则变化。
- 变更风险提示：对正文、目录、图表和参考文献等容易返工的模块标记风险等级。
- 受影响模块标记：目录和论文样张中会标出本版发生变化的格式模块。
- 当前模块变更对比：右侧规则面板展示上一版要求、当前要求和返工影响。
- 后台规则 CRUD：维护者可以新增、编辑、删除格式规则。
- 后台可视化编辑：格式项、要求说明、常见错误、版本变更说明都支持逐条增删，不需要手写 JSON。
- 后台规则变更项维护：维护者可以维护规则对应的上一版要求、当前要求、影响说明和风险等级。
- 版本发布：支持草稿、发布、归档状态。
- 更新日志：记录登录、规则修改、版本发布等操作。
- 学生个人检查进度：学生勾选检查项后会保存到后端，下次登录可以继续查看。

## 技术栈

- Vue 3
- Vite
- TypeScript
- Python
- FastAPI

## 本地运行

前端：

```powershell
E:\nodejs\npm.cmd install
E:\nodejs\npm.cmd run dev
```

浏览器打开：

```text
http://127.0.0.1:5173
```

后端：

```powershell
python -m pip install -r backend\requirements.txt
python -m uvicorn backend.app.main:app --reload --host 127.0.0.1 --port 8000
```

接口：

```text
GET http://127.0.0.1:8000/api/health
GET http://127.0.0.1:8000/api/rule-versions/current
```

前端会优先读取后端版本数据；如果后端没有启动，会自动使用本地备用数据。

## 版本路线

- V1：完成静态论文格式样张和悬浮规则查看。
- V2：增加格式规则版本对比和高风险变更提示。
- V3：接入 Python 后端，提供规则版本接口和前端数据回退机制。
- V3.1：增加学生登录、管理员后台、规则 CRUD、版本发布和更新日志。
- V3.x：持续完善规则变更维护、学生检查进度、发布预览和账号管理。
- V4：探索 Word 上传后的半自动格式检查。
