# 论文格式可视化样张

一个基于 Vue 的论文格式交互式模板原型。页面模拟一篇完整论文，用户悬浮或点击不同论文区域时，可以查看对应格式要求、常见错误和规则更新时间。

## V1 功能

- 模拟论文全文结构：封面、声明页、摘要、目录、正文标题、正文段落、图、表、公式、参考文献、致谢和附录。
- 左侧目录导航：点击后跳转到对应论文模块。
- 中央论文样张：以接近纸张的样式展示虚构论文内容。
- 右侧规则面板：展示当前模块的字体、字号、行距、缩进、编号、注意事项和常见错误。
- 规则数据独立维护：论文示例内容和格式规范分别存放，便于后续接入后端版本管理。
- 无真实个人信息：样张使用完全虚构的论文主题、姓名、学院和参考文献。

## 技术栈

- Vue 3
- Vite
- TypeScript

E:\nodejs\npm.cmd run dev
```

```
